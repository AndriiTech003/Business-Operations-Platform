# 05 · Business Operations Platform

> CRM + сделки + счета + задачи в одном рабочем пространстве, а в центре — **собственный durable workflow-движок** с визуальным конструктором: «КОГДА счёт просрочен, ЕСЛИ сумма > $1000, ТО уведомить менеджера, создать задачу, подождать 3 дня, отправить напоминание».

## Зачем этот проект в портфолио

| Навык | Как проявляется |
|---|---|
| **Durable execution** | Свой workflow-движок: версии определений, состояние шагов в Postgres, аренда шагов с heartbeat, ретраи, таймеры на дни вперёд, восстановление после падения воркера |
| **Языки и компиляторы (мини)** | Свой безопасный язык выражений (Pratt-парсер, без `eval`) с проверкой типов по схеме данных триггера и автодополнением в UI |
| **Сложный UI** | Визуальный конструктор (React Flow), канбан сделок (dnd-kit), таблицы с кастомными полями, воспроизведение запуска workflow прямо на графе |
| **Бизнес-домен** | Воронка сделок, счета со статусами и PDF, задачи, активности, кастомные поля |
| **Мультитенантность другим способом** | Prisma + client extension для tenant scoping (в проекте 01 — RLS). В ADR сравниваются оба подхода |
| **Очереди другим способом** | BullMQ (Redis), в проекте 01 — RabbitMQ. Разные инструменты под разные задачи |
| **Экосистема** | Realtime через `@scope/realtime-client` (проект 03), флаги через `@scope/flags-node` (проект 02), MCP-сервер для AI-агента (проект 06) |

## Что умеет продукт

- **CRM**: компании, контакты, активность (звонки, письма, заметки), теги, импорт CSV.
- **Сделки**: воронки со стадиями, канбан, суммы, вероятности, прогноз.
- **Счета**: позиции, налог, статусы (`draft → sent → partially_paid → paid`, `overdue`, `void`), PDF, публичная ссылка для клиента, отметка оплаты.
- **Задачи**: назначение, сроки, связь с любой записью, «Мои задачи», напоминания.
- **Кастомные поля** для компаний, контактов и сделок (text, number, money, date, select, multi-select, user, relation) с валидацией.
- **Workflows**: триггеры → условия → действия, задержки, ветвления, одобрения человеком, HTTP-запросы, история запусков.
- **Уведомления** в приложении (realtime) и по email; комментарии с @упоминаниями.
- **Глобальный поиск** (⌘K) по всем сущностям.
- **Отчёты**: воронка, выручка по месяцам, дебиторка (aging), активность команды.
- **MCP-сервер** `ops-mcp` — типизированные инструменты для AI-агента (проект 06) и для Claude Desktop или IDE.

## Главные гарантии (каждая доказывается тестом)

1. **Ни один шаг workflow не теряется**, если воркер убит посреди выполнения: аренда истекает, шаг подхватывается другим воркером.
2. **Побочные эффекты не дублируются** при повторе шага: письмо не уходит дважды (идемпотентный ключ шага передаётся в каждое действие).
3. **Таймеры переживают рестарты**: `wait 3 days` срабатывает, даже если за это время перезапустилась вся система.
4. **Запущенные workflow не ломаются** при публикации новой версии: каждый запуск закреплён за своей версией.
5. **Выражения безопасны**: из выражения нельзя получить доступ к чему-либо, кроме данных триггера и результатов шагов; бесконечные вычисления невозможны.
6. **Изоляция тенантов**: запрос без tenant-контекста падает, а не возвращает чужие данные.
